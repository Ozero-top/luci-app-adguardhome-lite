# AdGuard Home 管理中心 v1.3.7-6

本次更新为预置规则增加可切换的下载源，并移除与切换源冲突的「手动更新」。

## 新增

- **三个下载源**：过滤规则页档位右侧新增「下载源」下拉框，可选 jsDelivr（默认）、GitHub 直连、自建备用（`https://agh.ozero.top/git/AdguardHome-Rrules/agh-dist/`），三个源目录结构一致。
- **切换即更新**：切换下载源后，插件把已有预置列表的地址原地改到新源，并由 AdGuard Home 立即重新下载，不需要再点其它按钮。
- **自动换源**：新添加预置列表时优先用当前选定的源，失败后按 jsDelivr → GitHub 直连 → 自建备用 → 配置的 GitHub 反代（默认 `gh-proxy.org`）→ `ghfast.top` 重试。
- **日志可追溯**：每次切换写入「运行日志 → 订阅更新日志」，保留最近 100 次，包含迁移成功与失败数量。

## 变更

- **移除「手动更新」**：切换下载源或档位本身就会立即重新下载，原按钮与后端刷新动作一并删除，避免与切换源并发冲突。
- **不改动自定义订阅**：只迁移能识别为预置规则的列表，用户自行添加的黑名单 / 白名单保持原地址。

## 切换源会替换已有规则文件吗？

会，而且是原地替换，不会产生额外副本：

- 切换源只改写已有预置列表的 URL，列表数量不变，不新增订阅；
- AdGuard Home 重新下载后覆盖本地规则缓存，插件不保留旧源的规则文件，也不做备份；
- 自定义规则、白名单与其它订阅不受影响；需要回退时重新选择原下载源即可。

## 验证

- iStoreOS 25.12 测试设备：jsDelivr → 自建备用 → GitHub 直连来回切换，6 个预置列表全部迁移成功，规则条数保持 236,414 / 217,140 / 89,868 / 56,120 / 341，最终停留在 jsDelivr。
- 切换后列表数量不变，订阅更新日志记录迁移结果。

## 升级方式

页面内点击「发现 v1.3.7-6，立即更新」，或使用安装包 / 脚本：

```sh
opkg install --force-reinstall luci-app-adguardhome-lite_1.3.7-6_all.ipk
# 或
sh install.sh -v 1.3.7-6
```

## 兼容性

- OpenWrt 22.03 及更早：使用 `legacy` 安装包。
- OpenWrt 23.05 / 24.10 / iStoreOS 24.10：使用 modern 安装包。
- OpenWrt / iStoreOS 25.12（apk）：使用通用模式；apk 资产仍为实验性，失败会自动回退。
- 适配 AdGuard Home v1.0.0。

## 校验

Release 附带 `SHA256SUMS` 与 `manifest-1.3.7-6.txt`：

```sh
sha256sum -c SHA256SUMS
```

## 注意

- 切换下载源会触发 AdGuard Home 重新下载列表，期间过滤可能短暂使用旧缓存。
- 自建备用源不可用时会自动回退其它源，无需手动处理。
