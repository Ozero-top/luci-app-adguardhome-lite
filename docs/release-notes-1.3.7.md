# AdGuard Home 管理中心 v1.3.7

本次更新加入插件在线更新与强制更新/降级，并正式纳入家长控制保护、统一显示名和新的发布基础设施。

## 新增

- **插件在线更新**
  - 发现新版本后可在页面内直接更新，无需再跳转 Release 手动下载。
  - 两种渠道：国内加速（jsDelivr → gh-proxy → ghfast → 直连）与 GitHub 直连；节点失败自动切换。
  - 两种方式：源码覆盖（默认，跨固件通用）与安装包（opkg 用 ipk，apk 用 apk）；装包失败自动回退源码覆盖。
  - 实时显示阶段、下载百分比、耗时与日志；页面关闭后任务继续，重新打开可恢复进度；成功后自动刷新。
- **强制更新 / 降级**
  - 更新弹窗的「高级」区域可强制重装当前版本，或指定历史版本（含降级）。
  - 强制更新前自动备份 `/etc/config/adguardhome_lite` 到 `/etc/config/adguardhome_lite.bak`。
  - 源码安装写入版本标记，降级后仍能正确显示目标版本，不会反复提示更新。
- **家长控制保护**
  - 开启前试拨 `family.adguard-dns.com`，连不上直接拒绝开启。
  - 运行中由看护进程每 30 秒探测，连不上自动关闭家长控制，避免全屋断网。
- **发布基础设施**
  - 新增 apk 产物（实验性）与 `manifest-<版本>.txt` 更新清单。
  - 安装包 SHA256 校验；Release 资产自动同步到 `dist` 分支，供 jsDelivr 国内加速。

## 改进

- 插件显示名统一为「AdGuard Home 管理中心」；包名、UCI 配置、菜单路由保持不变。
- 家长控制、成人内容拦截等开关的说明文案精简，避免撑高卡片。
- 面板静态资源版本号更新，升级后强制刷新新界面。

## 升级方式

### 页面内更新（推荐）

打开「AdGuard Home 管理中心」，点击版本徽标旁的「发现 vX，立即更新」：

- 渠道选「国内加速」或「GitHub 直连」；
- 方式保持默认「自动（源码覆盖）」即可跨固件通用；
- 需要修复当前版本或回滚时，勾选「强制更新 / 降级（高级）」，输入目标版本。

### 安装包 / 脚本

```sh
opkg install --force-reinstall luci-app-adguardhome-lite_1.3.7-1_all.ipk
# 或
sh install.sh -v 1.3.7
```

apk 系统可使用 Release 中的 apk 资产（实验性），或在页面内选择源码覆盖。

## 兼容性

- OpenWrt 22.03 及更早：使用 `legacy` 安装包。
- OpenWrt 23.05 / 24.10 / iStoreOS 24.10：使用 modern 安装包。
- OpenWrt / iStoreOS 25.12（apk）：源码覆盖或 apk 资产（实验性）。
- 适配 AdGuard Home v1.0.0；旧内核自动回退兼容接口。

## 校验

Release 附带 `SHA256SUMS` 与 `manifest-1.3.7.txt`。下载后可执行：

```sh
sha256sum -c SHA256SUMS
```

## 注意事项

- apk 产物为实验性，安装失败会自动回退源码覆盖。
- 源码覆盖会直接覆盖插件文件；强制更新/降级前已自动备份 UCI 配置。
- 降级可能遇到配置结构变化，建议先在测试设备验证。
- 在线更新会重启 AdGuard Home，DNS 会短暂中断。
