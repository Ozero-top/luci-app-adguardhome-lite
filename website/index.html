Features

把复杂的部分，收进一个页面

装内核、接 DNS、看状态，三步完成。过滤规则和查询日志仍交给 AdGuard Home 自己的面板。

一键装内核

自动识别 CPU 架构，从官方源下载最新稳定版；支持 GitHub 反代与 fake-IP 环境。

低侵入接管

接管 53 端口，DNSMasq 自动移到 1745；停止或卸载时按原值恢复，不写公共 DNS。

兼容 Clash

自建 agh_dns_redirect 链，在 DNS 劫持之前收回 53 查询；劫持目标写 53、1745 还是 7874 都不影响过滤。

页内看统计

概览直接显示查询、拦截、恶意/钓鱼、大人内容四项数据，每 10 秒随状态刷新。

按设备放行

指定不参与接管的接口或客户端 IP/CIDR，这些查询直接交给 DNSMasq，不进入 AdGuard Home。

配置可维护

高级配置保存前自动 --check-config 并留备份；内置中文界面、11 个过滤规则和 1 个白名单。

DNS Takeover

接管 53 端口，
先过滤再分流

设备发出的 DNS 查询先进入 AdGuard Home 过滤，再交给 DNSMasq 和上游。逐设备统计、Clash fake-IP 与分流都能保留。

  • 接管 53 端口：默认推荐，能看到每台设备的真实 IP。
  • Clash 共存：agh_dns_redirect 链优先收回查询，不被劫持绕过。
  • 停止即恢复：切回接管前的端口、noresolv、resolvfile 和上游。

Install

选一种方式，装到路由器上

新版 LuCI、旧版 LuCI、25.12 apk 系统和国内网络都有对应方案。同一台设备只装一个。

# 新版 LuCI：上传后在 /tmp 执行
opkg install /tmp/luci-app-adguardhome-lite_1.3.0-1_all.ipk

# 旧版 LuCI（22.03 及更早）请把包名换成
# luci-app-adguardhome-lite_1.3.0-1-legacy_all.ipk
# 离线自解压包，内含 modern 与 legacy
sh /tmp/luci-app-adguardhome-lite_1.3.0-1.run
# OpenWrt / iStoreOS 25.12 及 apk 系统
curl -fsSL https://raw.githubusercontent.com/Ozero-top/luci-app-adguardhome-lite/main/install.sh | sh
# 国内网络：脚本与文件都走反代
curl -fsSL https://gh-proxy.org/https://raw.githubusercontent.com/Ozero-top/luci-app-adguardhome-lite/main/install.sh | sh -s -- -m https://gh-proxy.org
同一设备只装一个。modern 用于 23.05 / 24.10，legacy 用于 22.03 及更早。
先卸载旧插件。与 luci-app-adguardhome 冲突，旧服务需先停止。
校验文件。Release 页提供 SHA256SUMS，可核对安装包完整性。
25.12 用脚本。apk 系统无法安装 ipk，升级和卸载继续用 install.sh。

FAQ

常见问题

更多排查步骤见安装与使用说明。

AdGuard Home 助手和传统 AdGuard Home 插件有什么区别？

传统插件更偏向把 AdGuard Home 的配置项全部搬进 LuCI；本插件只做装内核、接 DNS、看状态三件事，默认三步完成，接管前记录 DNSMasq 原值，停止或卸载时自动还原。

OpenWrt 25.12 apk 系统怎么安装？

25.12 起默认使用 apk，不能安装 .ipk。直接运行 install.sh，脚本会补齐依赖、安装文件并清理 LuCI 缓存；后续升级和卸载继续用脚本。

需要先手动安装 AdGuard Home 吗？

不需要。插件自带内核安装流程，首次使用点「安装/更新内核」即可；已存在 /etc/AdGuardHome.yaml 时会直接复用。

启用后不能上网怎么办？

到概览页点「停止并关闭自启」，插件会恢复接管前的 DNSMasq 设置。仍异常可执行 /etc/init.d/adguardhome_lite stop 和 /etc/init.d/dnsmasq restart。

同时运行 Clash 时去广告不生效？

先检查 nft list chain inet fw4 agh_dns_redirect 是否有 redirect to :53。没有这条链时，重新保存一次「接管 53 端口」模式。

停止服务后面板打不开？

这是正常现象，面板随服务停止。重新点「启动服务」即可；如果服务已运行仍打不开，检查 UCI 端口与 YAML address 是否一致。

重启后内核消失？

内核装在 /tmp 内存位置时会这样。重新安装内核，或在基础设置里把安装位置改到内置存储。

卸载后 DNS 会恢复吗？

会。正常停止或卸载时只写回接管前记录的 DNSMasq 端口、noresolv、resolvfile 和 server，不会写入公共 DNS。
