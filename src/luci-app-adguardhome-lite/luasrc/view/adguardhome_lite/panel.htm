    3. 
					
  3. 打开控制台：用概览页显示的地址、账号和默认密码登录 AdGuard Home。
    4.

二、四种 DNS 接管方式，到底选哪个？

				

				
记住一句话：想看到每台设备、让所有域名都先过滤 → 「接管 53 端口」（装了 Clash、开着 DNS 劫持也照样能用）；不想让 AdGuard Home 占 53 端口 → 「Clash 前置」。剩下两种只在特殊情况用。

				

					

						
							
你的情况该选哪个为什么

						
						
							

								装了 Clash（DNS 劫持/转发开着），还想看到每台设备
								接管 53 端口
								插件会在 Clash 的劫持之前把设备的 53 查询收回 53，先交给 AdGuard Home 过滤，再经 DNSMasq（1745）→ Clash（7874）分流。
							

							

								没装 Clash
								接管 53 端口（默认）
								最直接：把 53 交给 AdGuard Home，所有设备默认都走它，过滤和统计都最完整。
							

							

								不想让 AdGuard Home 占 53，也不在乎逐设备统计
								Clash 前置
								Clash 先劫持，再把查询交给 AdGuard Home（5335）过滤；面板里来源全是 127.0.0.1，属于正常现象。
							

							

								没有程序抢 53，但想让 DNSMasq 继续当入口
								DNSMasq 上游
								DNSMasq 留在 53，收到查询后转给 AdGuard Home（5333）过滤。
							

							

								只想看看面板，或 DNS 已经由别的程序管了
								仅面板模式
								完全不动系统的 DNS，只开 13800 管理面板。
							

						
					

				

				
原来的「Clash 串联」已下线：DNSMasq 会优先用 Clash 写入的上游，查询被 Clash 抢先应答，AdGuard Home 实际收不到，旧配置会自动迁移到「接管 53 端口」。

				
切换方式时，与当前方式无关的设置会自动置灰：排除接口/客户端只在「接管 53 端口」可用；没装 Clash 时「Clash 前置」不可选；选「DNSMasq 上游」且开着 Clash 会提示上游可能被覆盖。置灰只是禁止修改，已保存的值不会丢。

			


			

				

					
三、每种方式的大白话说明

				

				
    
					
  • 接管 53 端口（默认）：相当于把「问路的前台」直接换成 AdGuard Home。设备一上来就问它，它先把广告域名拦掉，剩下的再转交给系统原来的 DNSMasq（被挪到 1745 端口）。
    
					什么时候用：想看到每台设备、让所有域名都先过滤；装了 Clash 也推荐这个。
    
					要注意：插件会自建一条 nft 规则，把设备的 53 查询在 Clash 劫持之前收回 53；如果这条规则没生效（面板会提示），查询仍可能被 Clash 抢走。
    
					不想被接管：访客 WiFi、IoT 网段、旁路由或某台自建 DNS 的设备，可在“基础设置 → 插件配置 → 不参与接管的接口 / 客户端”里排除；这些查询直接交给系统 DNSMasq（1745）应答，不进入 AdGuard Home，也不计入统计。
    • 
					
  • DNSMasq 上游：前台还是 DNSMasq，但它不再自己查，而是把所有查询转给 AdGuard Home（5333）过滤。
    
					什么时候用：你不想让 AdGuard Home 占用 53 端口，同时又没有程序抢 53。
    
					要注意：Clash 开着 DNS 劫持时不要用。
    • 
					
  • Clash 前置：设备先被 Clash 的劫持规则拉进 Clash 的 DNS（7874），Clash 再把域名丢给 AdGuard Home（5335）过滤，AdGuard Home 最后去问运营商/公共 DNS。
    
					什么时候用：不想让 AdGuard Home 占 53 端口，或者只关心过滤、不在乎每台设备各自的统计。
    
					要注意：Clash 内核必须运行；插件会自动把 Clash 的上游改成 127.0.0.1:5335，Clash 重启或「一键设置」后如果失效，回来重新保存一次即可。这个模式下面板里看到的来源都是 Clash（127.0.0.1），看不到每台设备的名字，属于正常现象。
    • 
					
  • 仅面板模式：什么 DNS 都不改，只把 13800 控制台开起来。
    
					什么时候用：只想先看看界面，或者你已经有别的 DNS 方案（比如另一台软路由）。
    • 
				

				
切换方式时，插件会先把 DNSMasq 恢复成你原来的设置，再按新方式配置，所以来回切换不会越配越乱。停止服务或卸载插件也会自动恢复。

			


			

				

					
四、插件里可以直接做的事

				

				
    
					
  • 基础设置 → 插件配置：启用/停止服务、DNS 接管方式、管理面板端口、内核安装位置与更新通道、GitHub 反代、数据工作目录、不参与接管的接口 / 客户端；下方同时提供面板密码修改和统计与日志保留（按天设置，保存后重启生效）。
    • 
					
  • 基础设置 → DNS 解析：上游 DNS 可选“自动（按接管方式）”或“自定义”；自定义支持 IP、tls://、https://、quic:// 以及 [/域名/]IP 条件转发。DNS 缓存可设 8～128MB、最小/最大 TTL 和乐观缓存；加密上游（DoH/DoT/DoQ）只在“Clash 前置”模式生效。
    • 
					
  • 基础设置 → 过滤规则：总开关控制全部订阅与自定义规则是否生效；成人内容拦截（HaGeZi NSFW）、安全搜索、浏览安全可一键启停；订阅支持添加、启停、删除，列表类型选“白名单（放行）”即作为白名单使用；自定义规则支持 @@ 白名单语法。以上修改立即生效，不需要重启。
    • 
					
  • 运行日志：查看系统日志中的 AdGuard 记录、内核安装日志和最近一次服务操作日志，支持自动刷新与下载；“查询日志”子页显示最近 20 条查询与拦截结果。
    • 
					
  • 高级配置：直接编辑 /etc/AdGuardHome.yaml，保存前自动执行 --check-config，校验失败不覆盖原文件，并保留 .bak 备份。
    • 
					
  • 概览：过滤统计（DNS 查询、已拦截、恶意/钓鱼、成人内容）直接取自 AdGuard Home 统计接口，可用“清空统计”重置；服务停止时数值显示“-”。
    • 
				

				
「接管 53 端口」下自定义上游会绕过本机 DNSMasq（1745），xxx.lan 等本地主机名将无法解析；需要保留本地解析时，请在自定义列表末尾加上 127.0.0.1:1745。

六、常见问题

				

				
    
					
  • 面板打不开：确认服务处于“运行中”；停止服务时面板也会关闭。
    • 
					
  • 启用后不能上网：点击“停止并关闭自启”，插件会恢复 DNSMasq 原始设置。
    • 
					
  • 13800 打不开：等待 5-10 秒；确认 UCI 端口和配置一致；旧安装需手动改成 13800。
    • 
					
  • 忘记密码：“基础设置 → 插件配置”。
    • 
					
  • 升级固件后：配置会保留，内核需重新安装。
    • 
					
  • 「恶意/钓鱼」「成人内容」一直是 0：「恶意/钓鱼」依赖「浏览安全」；「成人内容」只统计 AdGuard Home 原生家长控制，插件自带的「成人内容拦截」命中会计入「已拦截」。安全浏览依赖境外在线服务，开启后如果解析明显变慢，请把它关掉。
    • 
					
  • 广告拦不住：先确认 DNS 接管方式对不对（推荐「接管 53 端口」，并确认面板没有提示劫持绕过）；能过滤的是广告域名，抖音、微信、爱奇艺这类“同一个 App 自己域名里的广告”DNS 拦不了，需要客户端级方案。
    • 
				

			


			

				

					
七、开机启动顺序（不用手动干预）

				

				
    
					
  • 顺序：DNSMasq（START=19）→ AdGuard Home（START=95）→ Clash（START=99）。
    • 
					
  • 为什么这样排：先让 DNSMasq 起来（接管 53 时它在 1745 提供本地解析），再让 AdGuard Home 占好 53/5335，最后才启动 Clash 去劫持 53 并把上游交给 AdGuard Home。这样开机过程中每个环节的端口都已就绪，不会出现「Clash 先起来、AdGuard Home 还没监听」导致解析失败。
    • 
					
  • 你不需要做什么：安装或启用插件时，`/etc/init.d/adguardhome_lite` 已注册为 START=95、STOP=01，开机自动按上述顺序执行。
    • 
				

			


			

				

					
八、安全提示

				

				
    
					
  • AdGuard Home 面板默认对局域网开放，请勿把 13800 映射到公网。
    • 
					
  • 默认密码 admin123，建议首次登录后修改。
    • 
					
  • 接管 53 端口会调整 DNSMasq，请确认没有其他 DNS 服务冲突。
